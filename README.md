# LangChain Text Splitter 

A simple project to understand different text splitters in LangChain.

## Splitters Covered

- CharacterTextSplitter
- RecursiveCharacterTextSplitter
- RecursiveCharacterTextSplitter.from_language()
- TokenTextSplitter
- Semantic-based splitting

## Mini Splitter App

The `mini_splitter.py` file contains a simple Streamlit app where you can:

- Select a text splitter
- Set chunk size
- Set chunk overlap
- Enter your own text
- See the generated chunks
